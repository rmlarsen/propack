# Legacy archive — original Stanford homepage files

This directory contains **verbatim copies** of the files from the original PROPACK
homepage at `http://sun.stanford.edu/~rmunk/PROPACK/`, preserved for provenance.
They are reproduced as-is and retain their original wording (including the
original report-number typo discussed in [history](../history.md)). For
reformatted, openly licensed versions see the rest of the
[documentation](../index.md).

## Files

| File | Description |
|------|-------------|
| [`original-homepage.html`](original-homepage.html) | The original `index.html` of the PROPACK homepage. |
| [`README_v2.1.txt`](README_v2.1.txt) | Overview and installation notes for the Fortran 77 package, v2.1 (April 2005). |
| [`Readme.txt`](Readme.txt) | Overview of the MATLAB toolbox and implementation details. |
| [`license.txt`](license.txt) | Original 2005 BSD license notice. |
| [`lansvd.txt`](lansvd.txt), [`lanbpro.txt`](lanbpro.txt), [`laneig.txt`](laneig.txt), [`lanpro.txt`](lanpro.txt) | On-line help for the four MATLAB routines. |
| [`Changelog_v1.1`](Changelog_v1.1), [`Changelog_v1.2`](Changelog_v1.2), [`Changelog_v2.0`](Changelog_v2.0), [`Changelog_v2.1`](Changelog_v2.1) | Change logs for the Fortran 77 releases. |

The historical release tarballs (Fortran v1.0–v2.1, MATLAB v1.0/v1.1) and the
`TESTMATRICES` archive are large (~100 MB total) and are published as **GitHub
Release assets** rather than committed to the repository.
